# Devarity Shell v0.3 — Menu QA
Data: 2026-11-03

## Screenshot-based evidence (v0.2)
- Menu da Shell renderizou com 76 entradas de aplicativos, nomes e ícones.
- Janela do Kitty apareceu em outra captura.
- O dock parece sobrepor parte da janela quando esta ocupa a região inferior.
- Fastfetch mostra `Window Manager: niri`. Isso é uma observação a investigar, não uma conclusão de que o Devarity Lilith falhou: há mais de uma sessão gráfica ativa na máquina.
- Não há evidência visual de texto digitado na busca nem de lançamento por Enter.

- Menu CRT/industrial com cabeçalho técnico, índices e seleção destacada.
- Busca e navegação por seta para cima/baixo, Enter inicia a seleção, Escape fecha.
- Ajustes de dimensões responsivas. Mantida a API já usada (DesktopEntries/ScriptModel).
- Nenhuma mudança no compositor, na instalação do sistema ou no autostart.
