# Devarity OS — Brand Pack (Shell 0.5)

A logo foi enviada e aprovada pelo criador do Devarity OS. O símbolo com divisão central é a assinatura visual oficial.

## Assets publicados

- `devarity-mark-light.png`: branco/transparente, otimizado em 64×64 para interfaces escuras.
- `devarity-mark-dark.png`: preto/transparente, otimizado em 64×64 para interfaces claras.

São representações pequenas derivadas das artes originais fornecidas. Os 4 arquivos de alta resolução continuam como fonte de referência, fora do repositório. As duas versões com efeito de glitch são referências de motion, não logos estáticas para widgets.

## Uso

A logo clara é usada na Topbar, no Application Index e no Dock. A versão escura fica disponível para temas claros e documentação. Não esticar, não deformar nem aplicar brilho ou animações desconfortáveis.

**Licenciamento:** a marca não está automaticamente coberta por uma eventual licença open source do código. A política de utilização da marca por terceiros deve ser definida separadamente.

**Boot, login, suspensão e lockscreen não foram implementados nesta entrega.** Para essas telas, preparar versões de resolução maior e protótipos separados.
