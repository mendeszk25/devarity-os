# Referências visuais — uso interno

O usuário apresentou imagens Cyber Grunge monocromáticas e uma ficha de vigilância CRT azul. Outras referências do contexto incluem Retro Computing e Glitch Brutalism.

Não incluímos arquivos de terceiros neste pacote para evitar republicação sem checar direitos/licenças.

Diretrizes provisórias:
1. A estética de ruído, glitch e desordem serve a identidade, wallpaper e tela de bloqueio, **não à legibilidade de avisos críticos**.
2. Contraste forte e tipografia monoespaçada, com fallback legível.
3. Efeitos controláveis, opção de redução de movimento e modo econômico.
4. Evitar falsas mensagens de erro como adorno de interface.
5. Preservar a usabilidade do menu tradicional e atalhos.
